# PZ1 — Минимальный HTTP-сервер на Go с генерацией UUID

Учебный проект по дисциплине «Технологии создания программного обеспечения». 
Практическая работа №1: установка окружения Go, реализация минимального HTTP-сервиса на `net/http`, подключение внешней зависимости (`github.com/google/uuid`), сборка бинарника и проверка ответов.

---

## 1. Описание проекта и требования

### Что делает сервис

`helloapi` — это HTTP-сервер на чистой стандартной библиотеке Go (`net/http`). Он поднимается на локальном порту (по умолчанию `8080`) и предоставляет три маршрута:

| Метод | Маршрут    | Тип ответа           | Описание                                              |
|-------|------------|----------------------|-------------------------------------------------------|
| GET   | `/hello`   | `text/plain`         | Возвращает строку `Hello, world!`.                    |
| GET   | `/user`    | `application/json`   | Возвращает JSON с уникальным `id` (UUID) и `name`.    |
| GET   | `/health`  | `application/json`   | Возвращает статус сервиса и текущее время в RFC 3339.  |

Пример ответа `/user`:

```json
{
  "id": "3f1c1c5c-9a1b-4a6a-8a26-7b3f2f7d8b0b",
  "name": "Gopher"
}
```

Пример ответа `/health`:

```json
{
  "status": "ok",
  "time": "2026-09-30T15:04:05+03:00"
}
```

### Требования к окружению

- **Go** версии `1.22.x` и выше (проект собирается на `go 1.27.1`).
- **Git** любой актуальной версии.
- ОС: Windows / macOS / Linux. На Windows для корректного отображения кириллицы в консоли при необходимости выполните `chcp 65001`.
- Доступ к `https://proxy.golang.org` для скачивания зависимости `github.com/google/uuid`.

### Используемые зависимости

| Пакет                    | Версия  | Назначение                          |
|--------------------------|---------|-------------------------------------|
| `github.com/google/uuid` | `v1.6.0`| Генерация UUIDv4 в маршруте `/user`. |

Стандартная библиотека: `net/http`, `encoding/json`, `log`, `os`, `time`.

## 2. Команды запуска/сборки и примеры запросов

### 2.1. Проверка окружения

```powershell
go version
git --version
```

Ожидаемый вывод — версии `go1.22.x` (или новее) и `git version ...`.

### 2.2. Запуск из исходников (режим разработки)

Из корня проекта (там, где лежит `go.mod`):

```powershell
go run ./cmd/server
```

Ожидаемый вывод в логе:

```
Starting on :8080 ...
```

### 2.3. Сборка бинарника

```powershell
go build -o helloapi.exe ./cmd/server
.\helloapi.exe
```

### 2.4. Проверка эндпоинтов

В отдельном окне терминала:

```bash
curl http://localhost:8080/hello
# Hello, world!

curl http://localhost:8080/user
# {"id":"3f1c1c5c-9a1b-4a6a-8a26-7b3f2f7d8b0b","name":"Gopher"}

curl http://localhost:8080/health
# {"status":"ok","time":"2026-09-30T15:04:05+03:00"}
```

В браузере ответы открываются по тем же URL.

### 2.5. Проверка код-стайла

```powershell
go fmt ./...
go vet ./...
```

Обе команды должны завершаться без ошибок и предупреждений.

## 3. Структура проекта

```
PZ1_SCT-minimal_HTTP_server_uuid/
├── README.md                       # этот файл
└── helloapi/                       # Go-модуль example.com/helloapi
    ├── cmd/
    │   └── server/
    │       └── main.go             # точка входа: маршруты /hello, /user, /health
    ├── go.mod                      # паспорт модуля: имя, версия Go, зависимости
    ├── go.sum                      # контрольные суммы зависимостей
    └── helloapi.exe                # собранный бинарник (артефакт сборки)
```

Назначение файлов:

- **`go.mod`** — декларация модуля `example.com/helloapi`, требуемой версии Go и зависимости `github.com/google/uuid v1.6.0`.
- **`go.sum`** — хэши зафиксированных версий зависимостей; гарантируют одинаковый набор пакетов у всех разработчиков и защищают от подмены.
- **`cmd/server/main.go`** — исходный код HTTP-сервера (единственный файл с логикой).
- **`helloapi.exe`** — собранный исполняемый файл для Windows; артефакт можно перезаписать командой `go build`.

## 4. Примечания по конфигурации

### Порт

По умолчанию сервер слушает порт `:8080`. Порт настраивается через переменную окружения `APP_PORT`:

```go
port := os.Getenv("APP_PORT")
if port == "" {
    port = "8080" // значение по умолчанию
}
addr := ":" + port
log.Printf("Starting on %s ...", addr)
log.Fatal(http.ListenAndServe(addr, mux))
```

### Запуск на другом порту

**PowerShell** (текущая сессия):

```powershell
$env:APP_PORT="8081"
go run ./cmd/server
# -> Starting on :8081 ...
curl http://localhost:8081/hello
```

### Конфигурационные переменные

| Переменная   | По умолчанию | Назначение                                                |
|--------------|--------------|-----------------------------------------------------------|
| `APP_PORT`   | `8080`       | TCP-порт, на котором сервер принимает входящие соединения. |


### Типичные проблемы и решения

| Симптом                                                            | Решение                                                                                  |
|--------------------------------------------------------------------|------------------------------------------------------------------------------------------|
| `go: command not found`                                            | Перезапустить терминал после установки Go; проверить `PATH`.                            |
| `no Go files in ...` при `go run`                                  | Запускать команду из корня модуля: `go run ./cmd/server`.                                |
| `listen tcp :8080: bind: address already in use`                  | Смените порт через `APP_PORT=8081` либо остановите процесс, занимающий порт.             |
| Кракозябры в выводе `curl` на Windows                              | Выполнить `chcp 65001` в текущем окне терминала.                                        |
| `go: module github.com/google/uuid found, but does not contain...` | Проверить корректность `import "github.com/google/uuid"`, затем `go get` + `go mod tidy`. |
